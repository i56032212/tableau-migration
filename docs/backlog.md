## 二、開啟 Tableau 檔時還不支援的寫法

解析時列入 `unsupported`，報表進人工佇列（完整的清單在 README「已知限制與待驗證」最後的「尚未支援」）：

- `SCRIPT_*`、`MODEL_*`、`RAWSQL_*`
- LOD 的維度本身含 LOD；Relationship 模型中同一個彙總用到多張資料表的欄位
- Data Blending：同一個彙總混用兩個資料源的欄位、LOD 中次要資料源的欄位、次要資料源的條件與 Top N 篩選
- 預測的其他結果類型（趨勢、精確度等）、取消彙總的叢集、標題中的 Table Calculation 值
- 故事點記下的其他狀態（排序、欄列架的變更、註解）
- 合併集合的 XML 寫法（公開報表中還沒看到）、尚未併入 .tdsx 的 Published Data Source、舊版的 .tde 萃取
- 要求檢視者輸入自己的資料庫帳號或以檢視者身分模擬的連線（要改用列層級權限重寫）

另有一類**不會**列入 `unsupported`：編輯器裡可以設定，但 .twb 中的寫法沒有樣本、解析器不認得，從 Tableau 開啟的
報表會是預設值——次要計算與表計算的自訂排序順序、堆疊標記的開關、篩選控制項的自訂（顯示「全部」、搜尋、
套用按鈕等）、頁面的顯示歷程、Story 的格式、分頁顏色。盤點時要留意報表有沒有用到；拿到樣本就能補上解析

## 三、還沒驗證的

這些比第一部分重要：目標是數字可以驗證與 Tableau 相同，而下面每一項都還沒有在公司的環境證實。

1. **資料庫實機**：實跑過的只有 PostgreSQL、MySQL、Spark 與 Trino（Trino 靠 CI 的 Docker，最近沒有跑）。Oracle、SQL Server、
   Snowflake、Redshift、BigQuery、Teradata、Hive、Impala、Db2、SAP HANA 都是轉回 DuckDB 模擬。公司用到的資料庫要
   實測：方言轉譯的 SQL、連線設定、Initial SQL
2. **公司環境**：Live 連線的設定檔（`tmig connections template`、`tmig connections check`）、登入（OIDC 或反向代理）、

5. **Windows**：2026-11-16 第一次在 Windows 11 上跑一鍵檢查（ruff、pyright、完整的 pytest）、`regen_ir.py`、

- 修多行文字的列高時看到、沒有處理的：只有一行的文字字級很大時仍超出列高（20pt 的字在 20 像素的列中，相鄰

  沒有列的檢視（KPI、只有欄的文字表）中同一種格式的多行文字，第一行在中間、整段沒有置中；圓點與形狀的

  - 排序過的長條圖加上標記的註解之後，長條的順序變成依名稱（示範報表的 Sub-Category Profit：依利潤由大到小 →
    加上一個標記的註解 → 變成字母順序）。在 `tmig.render.vegalite` 的註解圖層，沒有動
  - 畫圖的附註裡有內部的代號：「參考線 ref_1 …」「預測（sum(f_profit)）：資料不足以預測」；現在看得到了，

  - dashboard 與 Story 的編輯器裡，畫圖的附註只標示「未能呈現」的那一種，單純的說明要到工作表的編輯器才列出
  - 平板大小（較短的一邊 501–800）的畫面沒有處理：工具列照舊折成幾列，「自動」大小的 dashboard 照舊隨畫面縮小

  - 訂閱工作的說明（執行紀錄、暫停通知的主旨）用建立訂閱時記下的報表名稱，報表改名後不會跟著變

**與 Tableau 差最多的（桌面版）**

- 檢視、各架、標題、座標軸、標記、圖例、dashboard 區塊都沒有右鍵選單
- 「顯示篩選」「顯示參數」在編輯器裡不出現控制項，要到檢視器才看得到
- dashboard 並排的版面不能用拖的排：沒有落點預覽、邊界拖不動、區塊搬不動
- 計算欄位編輯器沒有自動完成、函式清單與著色，欄位拖不進去
- 新做的圖外觀不同：離散日期的「自動」是長條不是折線，欄標題的位置與日期的寫法不同
- 分頁列：隱藏的工作表仍顯示、不能拖曳排序、工作表一律排在 dashboard 之前
- 連按兩下座標軸或標題沒有反應；座標軸與標題沒有排序圖示；圖例不能點選醒目提示或改色
- Delete 與拖出架外不能移除膠囊；Ctrl+W 是關閉報表（Tableau 是交換欄列）
- 色彩、工具提示、標籤、格式都是按確定才套用的對話框；色盤顯示內部代號
- 開啟後先進檢視模式；只能存 .tmigx；編輯器裡沒有匯出與列印

**與 Tableau 差最多的（伺服器端）**

- 首頁不能瀏覽內容：沒有 Project、縮圖、排序、擁有者、修改時間，也沒有報表的頁面
- 沒有分享鈕；改篩選後網址不變；`?Region=West` 這類網址參數沒有作用
- 相對日期與條件篩選的控制項唯讀；欄位標題與座標軸沒有排序圖示
- 內容的擁有者沒有畫面可以改名、移動、刪除、設權限、排萃取更新，都在只有管理員進得去的站台管理
- 點圖例不醒目提示、多選沒有合計、工具提示沒有檢視資料、檢視資料不依選取
- 檢視畫面上多出驗證用的「篩選組合」與每張工作表的「N 列 資料」；分頁是下拉選單
- PDF 要經瀏覽器的列印對話框，不能直接下載、不能一次匯出多張工作表
- 管理：沒有有效權限的檢視、沒有使用統計的畫面、不能匯入使用者

**兩邊都有的**：用語不一致（dashboard／儀表板、Story／故事、資料來源／資料源、Project、view）、英文與內部代號
外露（Grand Total、HTTP 狀態碼；篩選「頂部」的 `[Calculation_…]` 已修，其他地方還沒有逐一檢查）。

**沒有實測到的**：Tauri 外殼裡的原生對話框與安裝檔、列印與 PDF 的實際輸出、資料庫的 Live 連線與成功的萃取更新、
密碼與 OIDC 登入、常駐的排程器、大資料量與多人同時使用，詳見兩份原始紀錄的最後一節。
