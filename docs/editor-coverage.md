# 編輯器與 Tableau Desktop 2021.2 的功能對照

對照的基準是 Tableau Desktop 2021.2 的選單、窗格與對話框；右邊是桌面版編輯器（`web/src/editor`、`tmig.edit`）
目前的狀態。狀態只看「能不能在編輯器裡做出來」；從 .twb 開啟時能不能保留另外註明。

- ✅ 有　◐ 部分（說明缺的部分）　✗ 沒有
- 這份表是讀程式與測試整理的（2026-11），沒有逐項與 Tableau Desktop 並排操作比對；標 ✅ 的項目都有自動測試。

## 還沒有的功能，依常用程度排列

1. 百分比（分析＞百分比）、總計的位置與「總計使用」
2. 工作表上的篩選控制項、控制項的「只顯示相關的值」
3. 個別成員指定顏色、形狀的調色盤、線條類型
4. 把目前的狀態記到故事點
5. 資料源篩選、萃取設定在資料源分頁中編輯
6. 說明（Caption）、下拉線、巢狀排序、合併集合與集合控制項
7. dashboard 的平均分配內容、標籤的對齊
8. 格式：對齊、儲存格大小、複製貼上格式、活頁簿佈景主題、動畫
